## 界面结构

主界面有四个标签页，用 **十字键上/下** 在左侧标签间移动（或直接触控点击）：

| 标签页 | 用途 |
| :--- | :--- |
| **媒体库** | 你添加的媒体文件夹里的视频与音乐，自动扫描并记住 |
| **文件** | 浏览磁盘、SD 卡、外接硬盘上的文件，不受媒体库范围限制 |
| **历史** | 断点续播列表，按最近播放时间排序 |
| **设置** | 重新扫描、清空扫描缓存、插件管理、关于 |

启动后焦点默认在侧边栏的标签上。用 **十字键上/下** 在左侧标签之间移动，
按 **A** 进入，再用 **十字键** 在右侧列表里选择。

## 手柄按键速查

### 通用

| 按键 | 作用 |
| :--- | :--- |
| **A** | 确定 / 进入 |
| **B** | 返回上一级 / 退出播放 |
| **方向键 / 左摇杆** | 移动焦点 |
| **方向键 ← / →** | 在标签页与列表内容之间切换焦点 |

> **手柄确认键布局切换**：默认采用 Xbox / Steam 风格（A 确定 / B 返回）。如果你习惯 Nintendo Switch 风格（B 确定 / A 返回），可进入「设置 → 控制」随时切换，或启动时设置环境变量 `MUVIK_SWAP_AB=1`。

### 播放视频时

| 按键 | 作用 |
| :--- | :--- |
| **A** | 播放 / 暂停（控制栏显示时激活选中按钮） |
| **B** | 退出视频播放 / 关闭控制栏 |
| **十字键 ← / →** | 快退 / 快进 10 秒（控制栏显示时移动焦点） |
| **十字键 ↓** | 显示 / 隐藏控制栏（进度条与片名） |
| **LT / RT** | 音量 − / + 5%（按住连续调节） |
| **LB / RB** | 快退 / 快进 15 秒（按住连续调节） |
| **十字键 ↑** | 打开播放列表（控制栏显示时选中进度条） |
| **X** | 音轨选择（多语言配音切换） |
| **Y** | 字幕设置 |
| **R3（按下右摇杆）** | 循环切换播放倍速<br>`1.0x → 1.25x → 1.5x → 2.0x → 0.75x` |
| **L3（按下左摇杆）** | 循环切换画面比例<br>`原始 → 16:10 满屏 → 16:9 → 4:3 → 裁切铺满` |
| **START** | 锁定 / 解锁触控（防误触） |

### 键盘快捷键（桌面 / 键鼠模式）

| 按键 | 作用 |
| :--- | :--- |
| **F11** / **Alt + Enter** / **Cmd + F** | **全屏 / 窗口模式即时切换**（全局有效，自动记住偏好） |
| **空格（Space）** | 播放 / 暂停 |
| **方向键 ← / →** | 快退 / 快进 10 秒（按住连续调节） |
| **回车（Enter）** | 确定 / 进入 |
| **Esc / Backspace** | 返回上一级 |

> **16:10 满屏**是给 Steam Deck 的 16:10 屏幕准备的：多数影片是 16:9，
> 直接铺满会留黑边，这个模式会轻微拉伸填满屏幕。

> 注意 **X 键在不同界面含义不同**：在视频库**列表里**按 X 是「获取影片信息」
> （刮削），进入**播放界面后**按 X 才是「切换音轨」。

## 触控手势

播放视频时可直接用手指操作屏幕：

| 手势 | 作用 |
| :--- | :--- |
| **双击屏幕** | 播放 / 暂停 |
| **单击屏幕** | 显示 / 隐藏播放控制条 |
| **左半屏上下滑动** | 调节画面亮度 |
| **右半屏上下滑动** | 调节音量 |
| **水平滑动** | 快进 / 快退，带实时时间预览 |
| **按住屏幕不动（约 0.45 秒）** | **临时 2 倍速快进**，松手立刻恢复原速 |

**灵敏度说明**：上下滑动约 1.2 个屏幕高度对应满量程（与设备尺寸无关）；水平滑动划过整屏宽度
对应半个影片时长（最短 30 秒跨度）。

> **长按加速与倍速键（R3）的区别**：长按是**临时**的，松手就回到你原来设定的倍速，
> 不会覆盖 R3 选的档位；当前倍速已经 ≥ 2x 时，长按会在其基础上翻倍（上限 8x）。
> 手指按下后如果滑动超过约 12 像素，就按滑动手势处理，不会再触发长按。

> ⚠️ **亮度优先调屏幕背光，没有背光接口时才退回画面压暗。**
> Steam Deck、安卓与 Switch 上直接调系统背光（和 wiliwili 的做法一致），
> 系统界面也会跟着变暗；桌面 / macOS 没有通用背光接口，才在画面上叠黑色蒙版，
> 此时只影响播放画面。
>
> 手滑动过程中，状态栏的 HUD 会实时显示当前数值。

## 第一次使用

第一次启动时媒体库是空的。要看到影片，需要先添加文件夹。

### 添加媒体文件夹

1. 进入 **设置** 标签页
2. 选择 **添加媒体文件夹**
3. 选择存储位置，或用 **✏️ 手动输入路径**
4. 进入目标文件夹后，选择 **✅ 添加当前文件夹**

添加后会自动递归扫描子目录，结果会缓存下来。**下次启动不需要重新扫描。**

### 支持的存储位置

程序会自动探测：

- **Linux / SteamOS**：`/run/media/*/*`（含 Steam Deck 的 MicroSD 卡）
- **macOS**：`/Volumes/*`（外接磁盘与 SD 卡）
- 用户目录：`~/Videos`、`~/Movies`、`~/Music`、`~/Downloads`、`~`

如果自动探测没找到，用「手动输入路径」填写绝对路径即可。

### 重新扫描

添加了新的影片文件后：

- 进入 **设置**，选择 **重新扫描媒体库**
- 或在媒体库页面直接按 **Y**

扫描在后台进行，不会卡住界面。

## 播放视频

在 **媒体库** 或 **文件** 里选一个视频即可播放。

### 媒体库是怎么排的

媒体库首屏是**文件夹卡片**：一张卡对应一个你添加的媒体文件夹。卡上的画面是这个
文件夹里的前几个文件，右下角数字是总条目数。

- 按 **A** 进入文件夹，里面按「视频 / 音乐」分段列出
- 按 **B** 回到文件夹总览 —— 在总览上再按 **B** 才退出界面
- 卡片下方还有一段「最近添加」，跨文件夹取最新的 8 条，刚拷进来的片子直接在最上面

> 为什么不把所有文件排成一条列表：不同文件夹里常有一堆同名编号（`01.` `02.`），
> 视频和音乐混在一起时，「3:21」既可能是短片也可能是歌，一屏扫过去分不出来。

### 断点续播

播放过的影片会自动记录进度：

- 媒体库里会显示 `[已播 45%]` 或 `[已看完]`
- 再次打开时自动从上次位置继续（进度超过 15 秒才自动跳转）
- **历史** 标签页可以看到最近的播放记录

### 画面比例

按 **L3** 循环切换。五个模式：

| 模式 | 适用场景 |
| :--- | :--- |
| 原始自适应 | 尊重影片原始宽高比 |
| 16:10 满屏 | Steam Deck 屏幕，消除黑边 |
| 16:9 标准 | 普通宽屏视频 |
| 4:3 复古 | 老动画、老电视剧 |
| 裁切铺满 | 去掉上下黑边（会裁掉部分画面） |

### 倍速

按 **R3** 循环切换。适合追剧时加速观看。

## 播放音乐与后台播放

在 **媒体库** 的音乐段里选择一首曲子即可开始播放。

**关键特性：音乐是后台播放的。** 具体表现为：

- 退出播放器界面、切换标签页、浏览媒体库时，**音乐不中断**
- 主界面标题栏下方常驻一条「正在播放」状态条，显示曲名与进度
- 一首播完自动播下一首
- 每 10 秒自动保存一次进度，异常退出也不会丢

> 在 macOS 上，程序会自动抑制 App Nap，窗口失去焦点时也不会
> 降低调度优先级导致卡顿。

## 字幕

### 自动加载

- **内嵌字幕**：MKV / MP4 等容器里自带的字幕轨会被自动识别，
  包括 ASS 特效字幕与 PGS 蓝光图形字幕
- **外挂字幕**：与视频同名的字幕文件会自动加载，
  也支持 `影片名.zh.srt` 这类带语言标记的变体

### 手动设置

播放时按 **Y** 打开字幕面板：

- 按 **内嵌 / 外挂** 分组列出所有字幕轨
- 每条显示格式：`ASS 特效字幕`、`图形字幕 (PGS/SUB)`、`文本字幕`
- 可 **关闭字幕**
- 可 **📂 加载外部字幕文件**（输入文件路径）
- 可 **时间轴微调**：提前 / 延后 0.5 秒

选过的字幕轨会被记住，下次播放同一文件时自动恢复。

## 影片信息（刮削）

如果装了刮削器插件，可以给本地影片自动补上封面、评分、简介。

### 使用方法

1. 在 **媒体库** 里用方向键选中一个影片
2. 按 **X**
3. 程序会从文件名推测片名与年份并搜索

文件名会被自动清洗，例如：

| 文件名 | 提取结果 |
| :--- | :--- |
| `The.Matrix.1999.1080p.BluRay.x264.mkv` | 片名「The Matrix」，年份 1999 |
| `流浪地球.2019.1080p.mkv` | 片名「流浪地球」，年份 2019 |
| `[Group] Some Anime - 01 [1080p].mkv` | 片名「Group Some Anime 01」 |

刮削成功后，列表里会显示正式片名、评分、年份、片长、类型，而不是原始文件名。

> 没装刮削器插件时按 X 会提示去插件管理安装。

## 插件

插件是独立的动态库文件（`.so` / `.dylib`），提供两类能力：

| 类型 | 作用 |
| :--- | :--- |
| **视频源** | 接入 Emby、Jellyfin、自建媒体服务器等在线片库 |
| **刮削器** | 为本地影片提供元数据（封面、简介、评分） |

### 安装

进入 **设置** 标签页，选择 **插件管理**：

> **配置视频源插件**：安装后在插件管理里点击该插件，可以填写
> 服务器地址、用户名与密码。保存后自动重新加载，无需重启。
> 未配置的插件会在列表里标注 ⚠️ 未配置。

- **📦 从 ZIP 包安装插件**：输入 `.zip` 文件路径，自动解压并校验
- **🔄 重新扫描插件**：放好文件后按 **Y** 热重载，不用重启

也可以手动把插件文件放进插件目录，然后按 **Y** 重新扫描。

### 浏览插件内容

安装并配置好后，回到 **文件** 标签页，下方会出现插件条目。
点击即可进入浏览界面：

- 支持逐层进入子文件夹，按 **B** 返回上一级
- 视频与音频分列显示，选中即可播放
- 按 **Y** 刷新当前目录

### 安全说明

ZIP 安装会做以下检查，不通过会拒绝安装：

- 拒绝包含 `../` 或绝对路径的条目（防止把文件写到插件目录之外）
- 要求包内必须含 `.so` / `.dylib` / `.dll`
- 同名插件不会被覆盖
- 解压失败会整体回滚

卸载时只允许删除插件目录内的内容，不会误删其他位置。

## 网络存储（NAS / WebDAV）

Muvik 原生内置了对局域网 NAS 与 WebDAV 服务器的直接访问能力，无需安装编译任何插件即可开箱即用：

- **AList 聚合网盘**：一键连接 AList（默认端口 5244），无缝访问挂载的 115、夸克、阿里云盘、百度网盘与局域网存储。
- **群晖 / 威联通 NAS**：支持 Synology DSM 与 QNAP QTS 原生 WebDAV Server 套件。
- **标准 WebDAV**：支持 Nextcloud、ownCloud 等任意标准 WebDAV 服务端。

### 添加网络存储
1. 进入 **文件** 标签页。
2. 在「网络存储 (NAS / WebDAV)」区域选择 **添加网络存储 (WebDAV / NAS)**。
3. 选择服务预设（AList / 群晖 / 威联通 / 自定义 WebDAV）。
4. 填写服务器地址（支持 `http://` 与 `https://`）、用户名与密码。
5. 点击 **测试并保存**。程序会自动验证网络与鉴权；验证通过后即可在文件列表中直接浏览并流式播放！
6. 在已有网络源条目上按 **X** 键可随时管理或删除该源。

## 数据存放位置

所有配置都在一个目录里，遵循 XDG 规范：

| 路径 | 内容 |
| :--- | :--- |
| `~/.config/muvik/libraries.dat` | 你添加的媒体文件夹 |
| `~/.config/muvik/library_cache.dat` | 扫描结果缓存 |
| `~/.config/muvik/history.dat` | 播放进度与历史 |
| `~/.config/muvik/metadata.dat` | 刮削得到的影片信息 |
| `~/.config/muvik/plugin_config.dat` | 插件配置（服务器地址、账号等） |
| `~/.config/muvik/network_sources.json` | 内置网络存储配置（NAS 与 WebDAV 源） |
| `~/.config/muvik/plugins/` | 插件目录 |

如果设置了 `XDG_CONFIG_HOME`，则位于 `$XDG_CONFIG_HOME/muvik/`。

**备份或迁移**：把这整个目录复制走即可。

**彻底重置**：删除这个目录，程序会当作首次启动。

## 常见问题

### 界面没有文字 / 图标缺失

程序找不到资源目录。启动日志会打印一行：

```
资源目录: /path/to/resources
```

如果这行显示找不到，可以用环境变量指定：

```bash
MUVIK_RESOURCES=/path/to/resources ./muvik
```

资源目录里必须至少有 `font/` 子目录。

### 电量消耗快 / 风扇转得厉害

默认按 60 FPS 运行。如果设备性能较弱或想进一步省电，可以降低帧率：

```bash
MUVIK_FPS=30 ./muvik
```

空闲时 CPU 占用约 4–6%，播放 720p 视频约 6–8%（在有硬件加速的环境中）。
如果发现 CPU 长期接近 100%，多半是降低帧率的环境变量没生效或系统限制了显卡加速。

### 界面比例不对 / 想固定窗口大小

程序默认按显示器分辨率自适应。若需要固定尺寸（例如录屏、投影或
在超宽屏上限制窗口），用 `MUVIK_WINDOW` 指定：

```bash
MUVIK_WINDOW=1280x800 ./muvik   # Steam Deck 原生分辨率
MUVIK_WINDOW=1920x1080 ./muvik  # 1080p
```

界面会按窗口尺寸等比缩放，**布局不会因分辨率变化而错位**。
已验证 640×360、1024×600、1280×800、1280×720、1920×1080 下
布局形状一致（各区域亮像素占比差异 < 1 个百分点）。

播放不同比例的视频时，画面会按原始宽高比居中显示并自动留黑边：
4:3 影片在 16:10 屏幕上左右留边，16:9 影片在 16:10 屏幕上下留边，
**不会拉伸变形**。

### 媒体库扫描很慢

扫描是递归的，会遍历所有子目录。如果添加了根目录（如 `~/` 或整个磁盘），
会扫到大量无关文件。

建议只添加专门的影视 / 音乐文件夹。

### 视频能播但没声音

先按 **X** 检查音轨选择，确认有选中音轨且不是「静音」。
另外确认系统音量与音频输出设备正常。

### 音乐在后台播放时卡顿（macOS）

程序已自动抑制 App Nap。如果仍有问题，检查是否开启了
「低电量模式」——它会限制后台进程。

### 手柄没反应

确保手柄已被系统识别（Steam 环境下通常自动处理）。
在 Steam Deck 上，Gaming Mode 里通过 Steam 添加为「非 Steam 游戏」启动，
手柄支持最完整。

### 字幕是方块或乱码

字幕文件编码问题。Muvik 依赖 mpv 的字体回退机制，
建议使用 UTF-8 编码的字幕文件。

### 断点续播没生效

进度会一直记录，但**重新打开时只有超过 15 秒才自动跳转**——
避免刚开头几秒的误触被当成断点。

判定「已看完」的条件（满足任一）：

- 播放到时长的 **95%** 以上
- 距结尾不足 **30 秒**，且已播过一半

已看完的影片下次从头播放。

> 30 秒的下限是刻意加的：没有它，时长不足 30 秒的内容
> （短视频、歌曲）会在播 1 秒时就被判为看完，导致永远无法续播。
