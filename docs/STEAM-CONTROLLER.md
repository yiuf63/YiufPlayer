# Muvik Steam 控制器支持与过审指南

本文档面向 Muvik 上架 Steam 商店并获取官方 **「完全支持控制器」（Full Controller Support）** 标签与 **Steam Deck 绿标验证（Deck Verified）** 的完整技术方案与后台配置指南。

---

## 一、Steam 官方评级标准与判定要求

根据 Valve 官方 Steamworks 文档与 Steam Deck 兼容性审核规范，“完全支持控制器”是商店页面的最高控制器评级，其硬性要求如下：

| 官方指标 | 审核准则说明 | Muvik 达成方案 |
| :--- | :--- | :--- |
| **1. 全程无需键鼠** | 从启动游戏/应用、主界面导航、配置调整、媒体播放到退出程序，**全程任何时刻都不得强制要求鼠标或实体键盘**。 | **100% 达成**：基于 Borealis 原生离散焦点树，D-Pad 与左摇杆驱动所有控件导航。 |
| **2. 虚拟键盘自动呼出** | 任何需要文本输入的场景（搜索、输入 URL、密码、路径等），**必须支持纯手柄输入**，不得卡在桌面输入法。 | **100% 达成**：内置 QWERTY 手柄虚拟软键盘，同时桥接 Steam OSK 自动呼出。 |
| **3. 按键图元提示** | 界面上的操作提示必须显示手柄图标（如 Ⓐ / Ⓑ / Ⓧ / Ⓨ），**严禁出现键鼠字样（如“按回车”、“点击此处”）**。 | **100% 达成**：底部 Hint 栏与弹窗全部自动显示当前手柄物理按键图元。 |
| **4. 开箱即用手柄布局** | 插入 Xbox、PlayStation、Switch Pro 或 Steam Deck 控制器时，无需玩家在社区中自行查找键位，即插即用。 | **100% 达成**：提供官方标准 Gamepad 配置模板（`steam/gamepad_template.vdf`）。 |
| **5. 控制器退出闭环** | 玩家能够仅使用手柄退出应用回到 Steam 大屏幕模式，无需依赖 Alt+F4、实体键盘或强制切后台杀进程。 | **100% 达成**：主视图按 Ⓑ 键弹出退出确认框，设置页亦提供「退出 Muvik」单元格。 |
| **6. 显示模式与分辨率** | 自动适配常见电视与掌机屏幕比例，支持无黑边缩放与 16:10 / 16:9 沉浸显示。 | **100% 达成**：原生适配 Steam Deck 800p 以及电视 1080p / 4K 分辨率。 |

## 二、核心架构实现细节

### 2.1 内置手柄屏幕虚拟键盘（双保险机制）

针对传统桌面应用在电视/掌机上“无法手柄打字”的最大痛点，Muvik 实现了**双保险输入机制**：

1. **内置 QWERTY 屏幕虚拟键盘**（定义于 `external/borealis/library/lib/views/edit_text_dialog.cpp`）：
   - 当调用 `Application::getImeManager()->openForText(...)` 时自动弹出；
   - 具备 3 种布局模式：
     - **Mode 0**：小写字母、数字、常用标点；
     - **Mode 1**：大写字母（Shift 切换）；
     - **Mode 2**：符号键盘与 Web 常用短语（内置 `http://`、`https://`、`.com`、`.cn` 快捷键，输入网盘/WebDAV 路径无需逐字拼写）。
   - **手柄专属快捷键**：
     - `方向键 / 左摇杆`：在软键盘网格间平滑切换焦点；
     - `Ⓐ 键`：输入当前高亮按键的字符；
     - `Ⓑ 键`：取消并关闭对话框；
     - `Ⓧ 键`：全局退格（删除前一字符，无需移动焦点）；
     - `Ⓨ 键`：快捷插入空格；
     - `LB / RB`：左/右移动文本光标；
     - `START 键 (☰) / 点击「完成」`：确认并提交输入。
   - **全输入设备融合**：即使在手柄虚拟键盘开启状态下，若外接了物理键盘打字或触控点击屏幕，亦能同步生效，互不冲突。
2. **Steam OSK（Steam 屏幕键盘）自动唤起**：
   - 在 Linux / SteamOS / Steam Deck 环境下，`steam_deck.cpp` 会自适应探测 `$HOME/.steam/steam.pipe`、`$HOME/.local/share/Steam/steam.pipe` 与 `/tmp/steam.pipe`，自动下发 `steam://open/keyboard?Mode=0` 指令，双重保障用户能随心打字。

### 2.2 21 个全功能播放控制器按键映射

位于 `src/view/mpv_player.cpp`：

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **Ⓐ** | 播放 / 暂停 | 单击即时切换播放状态 |
| **Ⓑ** | 返回 | 停止播放并退出全屏，返回媒体浏览页 |
| **D-Pad ← / →** | 快退 / 快进 | 步长 10 秒（长按连续快进） |
| **LB / RB** | 快退 / 快进 | 肩键快捷快进退（与方向键步长一致） |
| **LT / RT** | 音量调节 | 步长 5%，屏幕显示即时音量条 HUD |
| **D-Pad ↑** | 快速呼出播放列表 | 右侧抽屉式展示同目录/剧集列表，直接换集 |
| **D-Pad ↓** | 呼出控制栏 / OSD | 激活底部播放进度条与功能按钮 |
| **Ⓧ** | 音轨切换菜单 | 弹出音轨列表，支持多国语言/多声道选择 |
| **Ⓨ** | 字幕设置菜单 | 切换内嵌/外挂字幕，调节字号、颜色与垂直边距 |
| **RSB（右摇杆下压）** | 播放倍速切换 | 循环切换：`1.0x → 1.25x → 1.5x → 2.0x → 0.75x` |
| **LSB（左摇杆下压）** | 画面比例切换 | 循环切换：`默认 → 16:9 → 4:3 → 2.35:1 → 拉伸` |
| **START（☰ 菜单键）** | 触控防误触锁定 | 锁定屏幕触控，避免掌机握持误碰 |

### 2.3 控制器退出闭环

1. **主界面 Ⓑ 键返回**：在根标签页（媒体库/文件/历史/设置）按 Ⓑ 键，将拦截默认行为并弹出控制器友好的 `brls::Dialog`（“确定要退出 Muvik 吗？”），焦点默认落在「取消」，避免误触；
2. **设置页显式退出入口**：在设置页底部提供带有关闭图标的「退出 Muvik」单元格，手柄选中按 Ⓐ 键即可安全退出进程。

### 2.4 手柄确认键风格自适应（AB 互换）

在设置 ->「控制」中支持一键切换：
- **Xbox / Steam 风格**：`Ⓐ 确认 / Ⓑ 返回`（Steam Deck、PC 与电视盒子标准）；
- **Nintendo Switch 风格**：`Ⓑ 确认 / Ⓐ 返回`（适合习惯日式主机的掌机玩家）。
环境变量 `MUVIK_SWAP_AB=1` 亦可由启动器直接指定。

## 三、Steamworks Partner 开发者后台配置指南

在将构建上传至 Steam 后，前往 Steamworks 开发者管理后台进行以下配置：

### 1. 开启“完全支持控制器”标签
1. 进入应用管理页面 -> **编辑应用元数据（Edit Store Presence）**；
2. 进入 **基本信息（Basic Info）** 标签页；
3. 找到 **控制器支持（Controller Support）** 栏目：
   - 选择 **完全支持控制器（Full Controller Support）**；
   - 勾选支持的控制器类型：Xbox 控制器、PlayStation 控制器（DualSense/DualShock 4）、Switch Pro 控制器；
4. 保存并在发布版本时发布该商店更改。

### 2. 发布官方默认 Steam Input 配置
1. 进入 **Steamworks 设置（Steamworks Settings）** -> **应用程序（Application）** -> **Steam 输入（Steam Input）**；
2. 在 **默认配置（Default Configurations）** 中添加标准手柄映射；
3. 可以直接使用仓库根目录提供的模板：
   - 模板文件：`steam/gamepad_template.vdf`
   - 将其上传为 **Official Configuration** 并标记为默认；
4. 确保在 Steam Deck 上默认选取的模板是 **“Gamepad（带摇杆触控板）”** 或 **“Standard Gamepad”**。

### 3. Steam 审核自检清单
在提交 Valve 审核员前，按以下清单走一遍流程：
- [x] 从 Steam 大屏幕模式（Big Picture）启动，无需碰触鼠标键盘；
- [x] 首次启动后，使用 D-Pad 导航浏览媒体列表；
- [x] 进入设置 -> 插件管理 -> 点击配置 WebDAV 地址，手柄虚拟键盘正常弹出，仅用手柄方向键与 Ⓐ 键能顺利打出 `http://` 与数字 IP；
- [x] 播放一段 1080p/4K 视频，测试快进退、音量调节、字幕切换；
- [x] 在主界面按 Ⓑ 键或在设置页选择「退出 Muvik」，通过手柄确认退出，进程干净退出回到 Steam 界面。

通过以上实现与配置，Muvik 即可 100% 满足 Valve 对 **Full Controller Support** 与 **Steam Deck Verified** 的所有验收指标。
