# 后续来源与扩展任务

**视频源**提供目录、媒体条目和播放地址。**刮削源**按文件线索查候选作品，提供片名、年份、简介与封面。项目已有原生 WebDAV、C ABI 与 QuickJS 插件入口，以及 `examples/tmdb_scraper_plugin/`、`examples/webdav_plugin/` 等参考实现。后台音乐使用已有 `AudioPlayer`，生命周期独立于视频播放页。

### 让玩家选择采用哪条资料

`FileBrowserActivity::scrapeItem()` 取首个刮削器。`PluginManager::scrapeForFile()` 从返回结果取第一个 ID，UI 在显示「完成」之前已经保存。建议先改这条单文件路径。

1. 选择资料源，预填解析出的片名和年份；玩家可纠正查询词。
2. 复用 `scrapeSearch()` 显示候选名、年份及来源。无结果时可修改查询或换源。
3. 对玩家选中的 ID 调 `scrapeFetchDetail()`，并列原值与拟采用值。确认后再调用 `MetadataStore::put/save`。
4. 取消、网络错误和候选过期均保留原资料与观看进度。先用两个同名不同年份的假返回值做原生回归，再由操作者用其有权使用的服务验证互通。

### 将配置绑定到目录与账号

每个已注册目录可继承默认源、选择一个首选源或关闭刮削。电影目录可记住中文资料源，游戏录屏目录可关闭。「移除目录」继续只改变片库索引。以后需要多账号或中英文两套服务时，引入实例标识，保留 `PluginConfigStore` 当前以插件 ID 存储的旧配置作为默认实例。先完成旧配置升级和两个实例互不覆盖的验收，再增加复杂的批量操作。

### 让网络失败后仍有下一步

在已有 WebDAV 浏览页显示来源名和失败目录。离线时给「重试」和「返回来源」，认证失效时给「编辑账号」，空目录保留可操作的返回项。SMB、Jellyfin 等其他接入逐项按真实服务器测试后再进入发行功能表。Steam 工坊已有目录发现路径，订阅、安装完成、版本更新和退订需要实际 Steam 环境验收。正式公开范围由后续版本决定。
