## 原生验证入口

在依赖已就绪的 Mac 测试工作树运行。UI 样本使用独立配置目录，记录退出码、通过数、失败数及跳过项。`functional` 的空历史场景原本断言第一个 A 进文件夹，增加续播时应保留并另测有历史场景。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target yiufplayer --parallel 4
./tests/run_tests.sh
XDG_CONFIG_HOME="$(mktemp -d)" python3 tests/tools/verify_ui.py --only functional --only screens
```
