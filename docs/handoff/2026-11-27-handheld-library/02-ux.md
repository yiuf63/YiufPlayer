# 影院蓝原生界面与操作约定

启动默认媒体库时，玩家首先看到上次那条可续播的视频、它所在的目录，以及按 A 后会发生什么。保留「媒体库 / 文件 / 历史 / 设置」四个目的地，优先改 `renderLibraryOverview()`。平铺视图仍由用户主动进入。[首页对照图](evidence/home-comparison.png)

| 页面状态 | 首焦点与布局 | 动作结果 |
|---|---|---|
| 首次打开／空库 | 主按钮写「扫描系统视频目录」，显示实际路径。其他探测位置按路径列出供勾选。空库暂时收起搜索、排序。 | A 扫描已选范围；允许手动选目录。拒绝权限可在原页重选。 |
| 有内容、无可续播记录 | 首焦点给第一个有效目录或文件。源名和当前路径可见。 | A 进目录或从头播放，返回到进入前的卡。 |
| 有可播断点 | 主视觉显示片名、实际季集号、已看时间 / 总时长。「继续播放」获焦，下面紧接真实文件夹。 | A 直接从保存位置播放；↓ 进入目录区。B 从视频返回同一媒体。 |
| 最近打开／已完成 | 阈值内的记录标「最近打开」，已完成的标「已看完」。只有确有下一集时才提供「播放下一集」。 | 最近打开从头播放。整季看完时提供重播或返回目录。 |
| 无图／来源离线 | 无可用图时收成一条深蓝色续播行，保留完整片名和进度。卡或 NAS 离线时保留来源名与观看记录。 | 离线主动作是「检查来源」，可切回其他可用目录。 |
| 多层目录 | 记住每一层的选中项和滚动位置。焦点停在长文件名时允许读全。 | B 回到进入前的文件夹；扫描、重排、缩略图返回后仍落在同一项目。原项移除时才取相邻有效项。 |

**画面和字号。** 使用影院蓝的深蓝背景、冰蓝焦点和静态取景。封面可用本地背景图、用户提供的封面或缓存帧。现有帧宽 320、高度上限 200；小图适合目录卡，大幅预览需要合适的图源。无图状态应先在 `thin` 配置通过验收。美术选择可参照可离线打开的交互稿。[视觉与流程参考](reference/cinema-blue.html)

**按内容区重排。** 跨页复用列数计算，输入为可用宽度、基础字号、观看距离档、最小卡宽和间距。Deck 手持常规档展示宽幅续播和目录卡；窄窗、TrimUI 或手动大字档改为两列或单列。长标题优先于文件大小。外接电视大字档与桌面可调整窗口分别验证。640×360 是开发回归尺寸，TrimUI 的正常握持距离仍需实机判读。

**手柄与播放页。** 首屏优先提示当前 A 动作、B 返回和更多选项；重扫、搜索和排序有可达入口。保留原生 X 音轨、Y 字幕及 ↑ 播放列表。自动出现的播放控制层允许直接 B 退出；主动唤出的控制层先用 B 收起。当前焦点下的图标配动作名，使用者可在掌机上自行找到换字幕的入口。
